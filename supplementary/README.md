# Supplementary materials — KANON-Index

Supplementary files cited in the manuscript (preprint v10).

## Supplementary Table
- **Table S1** — `Table_S1_per_researcher_indices.xlsx`: per-researcher decomposition
  (C, A, S, J, h-index, KANON, and within-field ranks under both indices) for all
  analysed profiles, with the data-quality flag. Lets any KANON–h disagreement be
  traced to its components and recomputed under user-chosen weights.

## Supplementary Figures
- **Figure S2** — `figures/Figure_S2_rankshift_by_field.png`: per-field breakdown of the
  rank-shift vs co-author-load relationship (fairness result).
- **Figure S3** — `figures/Figure_S3_early_components.png`: point-in-time component
  trajectories (T0 / T−5 / T−10) for the early-detection analysis.
- **Figure S4** — `figures/Figure_S4_early_percentile.png`: early-horizon percentiles
  (early-detection analysis).

All values are reproducible from the data and scripts in the repository root
(see the top-level `README.md`). Numbers verified under a strict real-data-only policy.
