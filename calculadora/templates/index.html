Sobre o KANON-Index

O KANON-Index (do grego kanon: cânone, padrão) integra quatro componentes para avaliar contribuição científica individual:

C = Impacto de citações (normalizado por campo) • A = Contribuição de autoria (penalização de hyperauthorship) • S = Sofisticação metodológica (S = β·Stext + (1−β)·Sconcepts) • J = Impacto de journal
