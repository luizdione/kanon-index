About the KANON-Index

The KANON-Index (from Greek kanon: canon, standard) integrates five components to evaluate individual scientific contribution:

C = Citation impact (field-normalized) • A = Authorship contribution (hyperauthorship penalty) • M = Methodological complexity (automatic technique detection) • R = Experimental cost • J = Journal impact

Data: OpenAlex API (open access) • Analysis: last 10 years • 100% browser-side calculation (no data sent to servers)
